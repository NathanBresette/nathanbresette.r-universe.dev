# NathanBresette's R-universe

Registry for [r-universe](https://nathanbresette.r-universe.dev): it builds the Rgent R package (`rstudioai`, from [Rgent-AI](https://github.com/NathanBresette/Rgent-AI)) for Windows, macOS and Linux.

```r
install.packages("rstudioai", repos = c("https://nathanbresette.r-universe.dev", "https://cloud.r-project.org"))
```
